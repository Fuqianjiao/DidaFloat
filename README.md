# DidaFloat

macOS 滴答清单桌面悬浮面板，通过滴答清单 MCP 显示和完成今日任务。

## 最新安装包

- 版本：0.3.7
- 平台：macOS 13+，Apple Silicon（arm64）
- 文件：`releases/DidaFloat-0.3.7-arm64.zip`
- SHA-256：`b734d7039430d79d2245bd909e63793c51697d7dce8b3337831fbf3669c3d604`

全局显示/隐藏快捷键默认为 `Control + Option + Command + D`，现在可以在设置中录制并修改，重启后仍会保留。

悬浮窗会伴随 macOS 桌面空间切换；macOS 15 及以上会加入其他应用的全屏空间，旧系统使用兼容模式。

解除固定后可拖动窗口空白区域到任意位置，固定后禁止移动；应用会记住上次窗口位置。

底部常显“创建需求”入口可直接打开指定的滴答清单页面；Chrome、Microsoft Edge 或 Safari 作为默认浏览器时，会优先复用已打开的滴答清单标签。

解压后打开 `DidaFloat.app`，在设置中填写滴答清单 API 口令。
