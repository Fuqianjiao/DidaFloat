# DidaFloat

macOS 滴答清单桌面悬浮面板，通过滴答清单 MCP 显示和完成今日任务。

## 最新安装包

- 版本：0.3.1
- 平台：macOS 13+，Apple Silicon（arm64）
- 文件：`releases/DidaFloat-0.3.1-arm64.zip`
- SHA-256：`5d488fc67baf392eda1b5efc0fb55e030028e0de9adc69929d728c513bd02cdb`

全局显示/隐藏快捷键：`Control + Option + Command + D`。

解压后打开 `DidaFloat.app`，在设置中填写滴答清单 API 口令。
