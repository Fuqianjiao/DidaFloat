# DidaFloat

macOS 滴答清单桌面悬浮面板，通过滴答清单 MCP 显示和完成今日任务。

## 最新安装包

- 版本：0.3.4
- 平台：macOS 13+，Apple Silicon（arm64）
- 文件：`releases/DidaFloat-0.3.4-arm64.zip`
- SHA-256：`d2487cd85c26f236b1c6a609b5edd40ff08749a3b45daa7aaafc20fcae5481bd`

全局显示/隐藏快捷键默认为 `Control + Option + Command + D`，现在可以在设置中录制并修改，重启后仍会保留。

悬浮窗会伴随 macOS 桌面空间切换；macOS 15 及以上会加入其他应用的全屏空间，旧系统使用兼容模式。

解压后打开 `DidaFloat.app`，在设置中填写滴答清单 API 口令。
